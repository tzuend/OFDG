\chapter{Methods}
\label{chap:methods}
\label{chap:stabilization}
This chapter defines the numerical method used in this work. The DG
formulation in \cref{chap:background} supplies the conservative evolution.
Adapted OFDG adds local damping, and KXRCF optionally determines which cells
receive it. The curvilinear construction gives these operations their physical
meaning on mapped elements. OEDG is described as a related method available
for comparison, followed by numerical controls and implementation assumptions.

\section{Baseline discretization and method composition}
The baseline is the weak DG formulation \cref{eq:rkdg-weak-form} with the
Rusanov flux \cref{eq:rusanov}. It uses a fixed scalar DG space, repeated for
each conservative component, and explicit Runge--Kutta time integration.
Periodic boundaries identify the corresponding traces; physical boundaries
supply an exterior state through the DG flux. The oscillation sensor uses
interior interfaces and does not replace this boundary treatment.

As a roadmap, denote a complete RKDG step by $\mathcal H_{\Delta t}$ and
the subsequent damping operation by $\mathcal F_{\Delta t}$, where
$\Delta t$ is the physical timestep. The vector $U^n$ contains the DG
coefficients at time $t_n$ and $U^*$ is the candidate state before damping.
The two operations are composed as
\begin{equation}
 U^*=\mathcal H_{\Delta t}(U^n),\qquad
 U^{n+1}=\mathcal F_{\Delta t}(U^*),
\end{equation}
The construction of $\mathcal F$ is developed from projections
(\cref{sec:ofdg-mathematics}), derivative jumps
(\cref{sec:projected-derivatives}), and damping rates
(\cref{sec:ofdg-rates}), before giving the assembled operator and its exact
frozen decay in \cref{sec:ofdg-decay}. With KXRCF, the active set is computed from $U^*$ before
applying $\mathcal F$. Without an oscillation filter, $\mathcal F$ is the
identity. The implementation defaults to post-step OFDG and stage-wise OEDG;
the location of filtering is part of the numerical method, not an incidental
software setting. Euler additionally uses the admissibility control in
\cref{sec:numerical-controls}.

\section{Putting the OFDG building blocks together}
\label{sec:ofdg-update-recipe}
The following sequence specifies one application of the default post-step
OFDG filter. Its inputs are the candidate DG coefficients $U^*$, the fixed
mesh and solution space, a damping duration $\Delta t$, and the chosen
wave-speed policy. Physical projection and derivative matrices and geometric
quadrature data have already been assembled as in
\cref{sec:curvilinear-mathematics,sec:ofdg-implementation}.
\begin{enumerate}
 \item If KXRCF is enabled, evaluate the component indicators from $U^*$
 and form the common active set $\mathcal A$ using
 \cref{eq:kxrcf-components}. Otherwise every element is active. An inactive
 element will retain its candidate coefficients exactly.
 \item Evaluate the physical global mean and sampled amplitude $A_c$ for
 each component, using \cref{eq:ofdg-global-scale}. These statistics include
 all elements, even when filtering is restricted to an active set. Initialize
 every element rate to zero; components with $A_c\leq10^{-14}$ receive no
 damping.
 \item Starting from $U^*$, compute the derivative states for all
 $0\leq|\alpha|\leq k$ with the parent rule in
 \cref{eq:curved-recursion}. Include neighbour states needed at shared
 interfaces. The state for $\alpha=0$ is the solution itself.
 \item On each interior face needed by an active element, evaluate both
 traces at matching physical quadrature points. Form the absolute-jump
 averages \cref{eq:ofdg-face-jump} with normalized physical weights, and
 evaluate each side's normal wave speed. Add its contribution from
 \cref{eq:ofdg-damping-rate} to the corresponding element rate. A face
 adjacent to an inactive neighbour still contributes to an active element.
 \item Hold these rates fixed. For each active element and component,
 retain $\Pi_K^0u_{h,c}^*$ and multiply each shell
 $(\Pi_K^j-\Pi_K^{j-1})u_{h,c}^*$ by
 $\exp(-\Delta t\sum_{l=0}^j\delta_{K,c}^{(l)})$. Sum the retained mean
 and attenuated shells to obtain the filtered coefficients.
\end{enumerate}
All indicators, amplitudes, derivatives, and rates in this application refer
to the same candidate state. Rates are not recomputed between shells. The
result is the map $\mathcal F_{\Delta t}(U^*)$ introduced at the start of
this chapter. Euler admissibility remains the separate control described in
\cref{sec:numerical-controls}; OEDG instead uses its own sensor and the
stage-wise placement described in \cref{chap:oedg}. The selected mesh,
initial and boundary data, CFL number, and final time must additionally be
specified for a reproducible experiment; their final selection remains
pending, rather than being implicit in this filter definition.

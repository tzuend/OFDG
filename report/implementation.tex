\section{Implementation assumptions and geometric scope}
\label{chap:implementation}
\label{sec:ofdg-implementation}
\label{sec:support-boundary}
The implementation separates equation-dependent face physics, geometry-dependent
operators, and damping. MFEM supplies meshes, finite element bases, geometric
transformations, and distributed ownership. This organisation allows the same
projection algebra to act on scalar fields and conservative systems.

The finite element space must be nonempty and discontinuous; the caller is
responsible for its validity and for rebuilding the filter after mesh changes.
The public OFDG interface provides construction, stabilization, and decay;
KXRCF supplies an independent optional activation mask.
The supported construction assumes full-dimensional elements, a fixed mesh,
and uniform solution order $k\geq1$. It covers affine intervals and polynomial
curved triangles, quadrilaterals, tetrahedra, hexahedra, and prisms. Different
supported element families may coexist at the same order. Moving meshes,
variable solution order, pyramids, and embedded surfaces are excluded.

Native NURBS geometry is not supported by the two-sided face path used with
the project's pinned MFEM version. A NURBS mesh may instead be explicitly
approximated by polynomial geometry before the filter is constructed. This
changes the geometric representation and is separate from the solution-space
$L^2$ projection derived above. It does not imply that MFEM lacks NURBS support
in general. The OEDG implementation is treated here as an affine comparator;
the curvilinear extension described in this chapter concerns adapted OFDG
and KXRCF.

\subsection{Reference data and physical operators}
\label{sec:curved-construction}
Reference basis evaluations and the derivative graph are reusable by finite
element signature. Physical mass, projection, and derivative matrices belong
to each curved element. The reference projector is sufficient only when the
constant affine Jacobian weight cancels. Element and face geometry data remain
fixed during the lifetime of a filter; a change in mesh geometry, topology, or
solution space requires reconstruction.

Curved integration uses quadrature order
$2k+2\max(0,\mathrm{OrderW})+8$, where MFEM's \texttt{OrderW} estimates the
transformation-weight order. Positive tensor or Duffy quadrature and symmetric
triangular sampling are used to reduce orientation-dependent sampling effects.
This is an integration policy, not a guarantee of exact integration for every
mapped function. The physical projection identities refer to the resulting
quadrature inner product unless exact integration is stated explicitly.

The implementation retains derivative coefficient states for every local
cell and rebuilds them for each new solution. For gated filtering, local faces
whose two neighbours are inactive are skipped before their geometry is
constructed. Adjacent damping shells reuse their shared projection. These
choices eliminate redundant work without changing the operator. The matrix construction is given in
\cref{sec:ofdg-projection-coefficients,sec:ofdg-coefficient-derivatives,sec:ofdg-face-evaluation};
the storage costs are specified in \cref{sec:operator-storage}.

\subsection{Distributed evaluation}
MPI distributes elements across processes, or ranks. An ordinary interior
face contributes to both adjacent elements. At a shared face, a rank imports
neighbour coefficients and accumulates only its own element's contribution;
the adjacent rank performs the complementary operation. Global solution
amplitudes require collective reductions. Local and imported elements use the
same physical operator construction, so an MPI interface has no additional
physical boundary condition.

Geometry caches are fixed, but their integration-point state and the working
arrays are mutable. Concurrent applications of the same filter object are
therefore unsupported. This ownership convention keeps numerical state
separate from reusable geometric data.

\subsection{Runtime data and storage costs}
\label{sec:operator-storage}
Affine volume means and sampled extrema use quadrature of order $2k+1$;
curved elements use the geometry-dependent rule in
\cref{sec:curved-construction}. These are the samples used for $A_c$ in
\cref{eq:ofdg-global-scale}, including its stated small-amplitude cutoff.
The public semidiscrete interface uses the same rates as exponential decay,
but returns the coefficient vector of \cref{eq:ofdg-damping-operator}.

Derivative coefficient storage is allocated persistently for every local
element and rebuilt for each candidate state. Each interior face stores
its two evaluation matrices and normalized quadrature weights. There is no
cache eviction or replacement policy in the derivative or face loop.
To make the memory implications explicit, let $N_k(K)$ be the number of
coefficients on element $K$ and $N_{q,F}$ the number of face quadrature
points. The derivative graph contains $\binom{k+d}{d}$ states per
component and element. The corresponding storage scales as
\begin{align}
 &\mathcal O\!\left(\sum_{K\in\mathcal T_h}dN_k(K)^2\right)
 &&\text{for physical derivative matrices},\\
 &\mathcal O\!\left(\sum_{K\in\mathcal T_h}mN_k(K)\binom{k+d}{d}\right)
 &&\text{for derivative coefficient states},\\
 &\mathcal O\!\left(\sum_{F\in\mathcal F_h^{\mathrm i}}N_{q,F}
       [N_k(K^-)+N_k(K^+)+1]\right)
 &&\text{for face evaluation data}.
\end{align}
The sums allow mixed element families with different coefficient counts.
On one MPI rank they describe its local elements and ordinary interior
faces; shared-face neighbour buffers require additional storage.
These estimates cover the listed arrays, not the entire solver: projection
matrices, geometric data, and runtime scratch arrays also occupy memory.
Reusable affine operators avoid duplicating reference data, whereas curved
physical projection matrices must be assembled per element. This storage
policy trades memory for reuse of fixed operators and avoids rebuilding
them during every timestep.

\subsection{Verification criteria}
\label{sec:verification-criteria}
The algebra suggests independent checks: constants and component-wise cell
means should be preserved; inactive cells should remain unchanged; and a
change of coefficient basis should represent the same filtered function.
Curved first derivatives can be compared with an independently assembled
physical projection. Recursive higher derivatives require manufactured-solution
refinement studies, since their definition alone supplies no convergence
rate. Quadrature sensitivity, geometric parameterization, and serial/MPI
agreement are separate checks of the geometric realization.

These checks distinguish consistency of an implementation from the accuracy
and robustness of a complete simulation. Their selected numerical evidence,
along with comparisons between methods, belongs in the Results chapter once
the experimental programme has been agreed.

\chapter{Reproducibility and Study Design}
\label{app:reproducibility}

From the repository root, the draft workflow is
\begin{quote}
\begin{verbatim}
make test
make test-study
make study-quick
make figures-draft
make report-draft
\end{verbatim}
\end{quote}
The first command builds sanitizer-enabled serial tests and runs the two-rank
partition test.  The second validates analysis code and the independent WENO
solver.  The reduced study exists to exercise the complete data path; its
outputs are not final numerical evidence.

The proposed full design is inspected without running solvers using
\begin{quote}
\texttt{make study-plan}.
\end{quote}
This produces an expanded CSV and an estimated runtime summary.  Because the
full manifest is marked \texttt{draft}, \texttt{make study-full} exits before
building or launching a solver.  Execution becomes possible only after the
matrix has been reviewed and its manifest status is changed to
\texttt{approved}.

Raw logs, rank-local sampled profiles, and the long-form CSV are written below
\texttt{measurements/study/<profile>}.  Draft report assets are mirrored under
\texttt{report/generated/draft}; approved final assets use the separate
\texttt{report/generated/final} directory.  Each numerical row records its
exact command, source revision, compiler, MFEM revision, host, and UTC
timestamp.  Numerical failures remain rows with their exit code, diagnostic,
and detected failure time.

Live GLVis output can be enabled for the advection, Burgers, and Euler drivers
with \texttt{-vis}; \texttt{-vs} selects the timestep interval between updates.
Euler can additionally write rank-local MFEM solution files with
\texttt{-save}.  These paths are intended for interactive verification only;
every thesis plot is generated headlessly from recorded CSV or profile data.
